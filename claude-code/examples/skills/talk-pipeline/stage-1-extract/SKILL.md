# 演讲流水线第 1 阶段：提取

将原始素材（文章、转录稿、笔记或混合素材）转化为结构化摘要，供流水线下游阶段使用。自动检测素材类型。

## 适用场景

- 从任何原始素材开始准备新演讲
- 演讲流水线的第一步（始终在其他阶段之前运行）
- 在确定演讲方向前审核现有素材

## 本 skill 做的事

1. **收集元数据** — 如未提供，询问 slug、活动、日期、时长、受众、模式
2. **读取素材** — 加载素材文件或内联内容
3. **检测素材类型** — 根据内容信号判断是 REX（真实世界证明）还是概念型（想法/论点）
4. **提取叙事弧** — REX 类按时间顺序，概念类按主题顺序
5. **提取数据指标** — 所有可量化的数字及其来源
6. **识别主要主题** — 3-7 个主题
7. **标记缺口** — 完整演讲所缺少的内容
8. **写入 `{slug}-summary.md`**

## 输入

必填项：
- 素材文件路径或内联内容（文章 `.mdx`、转录稿 `.md`、笔记）
- 元数据：`slug`、`event`、`date`、`duration`、`audience`、`type`（--rex 或 --concept）

如果元数据缺失 → 先用 `AskUserQuestion` 询问，再继续。

## 输出

`talks/{YYYY}-{slug}-summary.md`

## 素材类型检测

| REX 信号 | 概念型信号 |
|---------|-----------|
| 具体日期 | 论点、论述 |
| 可量化的指标 | 泛化观察 |
| 项目/工具名称 | 趋势观察 |
| Commit、发布、PR | 类比、比喻 |
| "我发布了"、"我们构建了" | "我认为"、"在我看来" |

如果是混合类型 → 在摘要中同时注明两种成分。

## 输出格式

```markdown
# 演讲摘要 — {暂定标题}

**Slug** : {slug}
**活动** : {event}
**日期** : {date}
**时长** : {duration} 分钟
**受众** : {受众描述}
**检测到的类型** : REX | 概念型 | 混合型
**素材来源** : {素材文件路径}

---

## 叙事弧

{弧线描述：3-5 句话。REX 类按时间顺序，概念类按主题顺序。}

## 主要主题

| # | 主题 | 简短描述 | 权重 |
|---|------|---------|------|
| 1 | {主题} | {描述} | 高/中/低 |
...

## 提取的关键指标

{素材中所有可量化的数字}

格式：`{数值}` — {背景} — 来源：{章节/页码/git}

示例：
- `1,200 次提交` 历时 7 个月 — 来源："加速"章节
- `-97% 流量` SSE 迁移后 — 来源：CHANGELOG v1.1.0

如无 → "未发现可验证的指标（概念模式）"

## 叙事潜力

{3-5 句话，描述素材的优势和可能的叙事角度。
这个演讲的潜在亮点是什么。可能缺少什么。}

## 已识别的缺口

- [ ] {缺口 1} — {如何填补}
- [ ] {缺口 2} — {如何填补}

如无明显缺口 → "未发现重大缺口。"

## 对后续阶段的建议

- **研究**：{建议 / 不适用（概念模式）} — {原因}
- **概念**：{优先探索的主题}
- **定位**：{素材中已呈现的角度}

---

*由 talk-stage1-extract 生成 — {date}*
*素材来源：{source path}*
```

## 指标提取规则

- 四舍五入时必须注明
- 始终注明指标的来源
- 如果两个来源有矛盾 → 同时标注两者，不擅自选择其一
- 不为填补缺口而虚构指标
- 进化数据使用 `{之前} → {之后}` 格式

## 反模式

- 模糊摘要（"这篇文章讲的是 AI……"）
- 遗漏指标——即使是带来源的近似值也要记录
- 隐藏缺口——明确指出比假装它们不存在要好
- 无正当理由更改检测到的类型
- 虚构素材中不存在的叙事弧

## 验证清单

- [ ] 检测到素材类型并有理由支撑
- [ ] 叙事弧以 3-5 句清晰句子呈现
- [ ] 所有可量化指标均已提取并注明来源
- [ ] 主要主题已列出（最多 3-7 个）
- [ ] 缺口已明确标识
- [ ] 文件已保存至 `talks/{YYYY}-{slug}-summary.md`

## 使用建议

- 如果你想验证素材是否可用，可在运行编排器之前单独运行本 skill
- 摘要是基础——每个下游阶段都会读取它
- 混合素材（部分 REX、部分概念型）完全可以——清楚地命名两种成分即可

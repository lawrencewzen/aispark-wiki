# 代码质量套件插件

代码分析、重构与代码规范强制执行。

## 安装

```bash
bash install.sh
```

## 组件

- **refactoring-specialist 智能体** — 自动化代码改进
- **clean-code-reviewer 智能体** — 代码质量标准执行
- **/refactor 命令** — 带验证的安全重构
- **/optimize 命令** — 性能优化

## 快速开始

```bash
# 重构一个文件或目录
/refactor src/auth/

# 分析代码质量
/audit-codebase

# 获取设计模式建议
/design-patterns
```

## 功能特性

✓ 复杂度分析
✓ 重构建议
✓ 设计模式指导
✓ 性能优化
✓ 可维护性评分

# DevOps 流水线插件

CI/CD 自动化、部署与基础设施管理。

## 安装

```bash
bash install.sh
```

## 组件

- **devops-sre 智能体** — 基础设施与部署专家
- **/ship 命令** — 完整部署工作流
- **GitHub Actions 工作流** — 在你的仓库中自动化 CI/CD

## 快速开始

```bash
# 部署到生产环境
/ship --env production

# 检查部署状态
!git log --oneline -5

# 配置 CI/CD
# 查看 .github/workflows/claude-code-review.yml
```
